# Security policy

## Supported versions

| Version | Supported |
|---|---|
| 1.x | Yes |
| < 1.0 | No |

## Reporting a vulnerability

Please do **not** open a public issue for security problems. Report them
privately through
[GitHub security advisories](https://github.com/sanket-manohar/kaleidoscope/security/advisories/new).

Include the affected version, steps to reproduce and the possible impact.
You will receive an answer as soon as possible. Fixes are released as new
versions and described in the changelog.
